# 💗 1st Anniversary — จดหมายถึงเธอ

เว็บไซต์ static หน้าเดียว (HTML / CSS / JavaScript) สำหรับวันครบรอบ 1 ปี
เปิดเว็บมาเจอซองจดหมายปิดผนึกด้วยตราหัวใจ ต้องใส่ "วันที่ที่เราเริ่มต้น" เพื่อเปิดอ่าน
ข้างในเป็นไทม์ไลน์ความทรงจำจากอดีตไล่ลงมาถึงปัจจุบัน

## วิธีแก้เนื้อหา

เปิด `assets/js/data.js` ไฟล์เดียวจบ

**1) รหัสเปิดจดหมาย + วันเริ่มต้น**

```js
window.APP_CONFIG = {
  passcode: '19082025',                       // DDMMYYYY (ตัวเลข 8 หลัก)
  startDate: new Date(2025, 7, 19, 0, 0, 0),  // เดือนนับจาก 0 → 7 = สิงหาคม
  hint: 'ใบ้ให้นิดนึง : วันที่เราตกลงเป็นแฟนกัน 💌'
};
```

**2) เรื่องราวในไทม์ไลน์** — เพิ่ม/ลบ object ใน `window.STORY` ได้ไม่จำกัด
เรียงจากบน (อดีต) ลงล่าง (ปัจจุบัน) ระบบจะสลับซ้าย–ขวาให้เองอัตโนมัติ

```js
{
  src: 'assets/timeline/01.jpg',   // รูปหรือวิดีโอ — ดูจากนามสกุลไฟล์เอง
  poster: '',                      // ภาพนิ่งก่อนวิดีโอเล่น (ใส่เฉพาะวิดีโอ)
  date: '19 AUG 2025',             // เว้นว่าง '' = ป้ายวันที่ไม่ขึ้น
  title: 'วันแรกที่เราเริ่มต้น',
  text: 'คำบรรยายสั้น ๆ ...',       // เว้นว่าง '' = บรรทัดนี้ไม่ขึ้น
  alt: 'คำอธิบายสำหรับ screen reader'
}
```

**3) ใส่รูป / วิดีโอ** — วางไฟล์ไว้ใน `assets/timeline/` แล้วแก้ `src:` ให้ตรง
แนะนำสื่อ **สี่เหลี่ยมจัตุรัส 1:1** ราว 1200×1200 px ถ้าไม่จัตุรัสระบบจะ `object-fit: cover` ครอปกลางให้เอง

- **รูป** : `.jpg` `.png` `.webp`
- **วิดีโอ** : ต้องเป็น **`.mp4` (H.264)** เท่านั้น — เล่นเองอัตโนมัติ วนลูป ไม่มีเสียง
  และจะเล่นเฉพาะตอนที่เลื่อนมาถึง (IntersectionObserver) เพื่อไม่ให้เปลืองเน็ต

> ⚠️ คลิปจาก iPhone มักเป็น **HEVC ใน `.mov`** ซึ่ง **Chrome / Firefox เล่นไม่ได้**
> (ทดสอบแล้ว: Chrome โหลดไฟล์ได้แต่ภาพออกมาเป็น 0×0) ต้องแปลงก่อนด้วย:
>
> ```bash
> ffmpeg -i คลิป.mov -c:v libx264 -profile:v high -pix_fmt yuv420p \
>        -crf 26 -preset slow -an -movflags +faststart คลิป.mp4
>
> # ภาพนิ่งสำหรับ poster
> ffmpeg -ss 0.3 -i คลิป.mov -frames:v 1 -q:v 4 คลิป-poster.jpg
> ```
>
> ไฟล์ `.mov` ต้นฉบับถูกใส่ไว้ใน `.gitignore` แล้ว จะไม่ถูก push ขึ้น GitHub

**4) ข้อความ hero / ท้ายจดหมาย** — แก้ตรง ๆ ใน `index.html`

## ขึ้นออนไลน์ : GitHub Pages

เว็บนี้เป็น static ล้วน ไม่มี build step — GitHub Pages เสิร์ฟไฟล์ตรง ๆ ได้เลย

**1) สร้าง repo แล้ว push**

ไปที่ https://github.com/new → ตั้งชื่อ → เลือก Public หรือ Private (อ่านข้อแตกต่างด้านล่าง)
→ ไม่ต้องติ๊ก Add README / .gitignore / license

```bash
git remote add origin https://github.com/<username>/<repo>.git
git push -u origin main
```

**2) เปิด Pages**

ที่ repo → **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**

รอ 1–2 นาที จะได้ลิงก์ `https://<username>.github.io/<repo>/`

> **อัปเดตเว็บทีหลัง** แค่ `git push` ขึ้น `main` GitHub จะ deploy ให้เองอัตโนมัติ
>
> ไฟล์ `.nojekyll` ในโปรเจกต์มีไว้กัน GitHub เอาไปประมวลผลด้วย Jekyll
> ถ้าไม่มีไฟล์นี้ โฟลเดอร์หรือไฟล์ที่ขึ้นต้นด้วย `_` จะถูกข้าม

**public หรือ private?**

| | Public repo | Private repo |
|---|---|---|
| ค่าใช้จ่าย | ฟรี | ต้องมี **GitHub Pro** (~$4/เดือน) |
| โค้ด / รูป / คลิป บน GitHub | ใครก็เปิดดูและโหลดได้ | เห็นเฉพาะเจ้าของ |
| ตัวเว็บ | ใครมีลิงก์ก็เปิดได้ | ใครมีลิงก์ก็เปิดได้ (เหมือนกัน) |

GitHub Pages บนแพลนฟรี **ใช้ได้กับ public repo เท่านั้น** ถ้าตั้ง repo เป็น private
โดยไม่มีแพลน Pro เมนู Pages จะขึ้นว่าต้องอัปเกรดก่อน

## ⚠️ ขอบเขตของความเป็นส่วนตัว — อ่านสักนิด

**ไม่ว่า repo จะ public หรือ private ตัวเว็บก็เปิดได้ด้วยลิงก์เสมอ** ไฟล์รูปและคลิปโหลดได้จากลิงก์ตรง ๆ
ที่ป้องกันไว้แล้วคือ **ไม่ให้ Google เก็บเข้า index** (`robots.txt` + meta `noindex`) เว็บจึงหาไม่เจอจากการค้นหา

รหัสเปิดจดหมายถูกเช็คฝั่ง client ทั้งหมด **ใครกด View Source หรือเปิด `data.js` จะเห็นรหัสทันที**
มันคือลูกเล่นให้บรรยากาศ ไม่ใช่ระบบความปลอดภัย

ถ้าใช้ **public repo** ให้เข้าใจตรงกันว่ารูปและคลิปทั้งหมดใน `assets/timeline/`
กลายเป็นไฟล์สาธารณะที่ใครก็โหลดได้ ไม่ใช่แค่คนที่มีลิงก์เว็บ

## เทคนิคที่ใช้

- **GSAP 3.12 + ScrollTrigger** (โหลดผ่าน CDN) — intro, เปิดซองจดหมาย, reveal ไทม์ไลน์, parallax, เส้น progress
- ถ้า CDN โหลดไม่ขึ้น เว็บยังใช้งานได้ปกติ (มี fallback `.no-gsap`)
- รองรับ `prefers-reduced-motion` — ผู้ใช้ที่ปิดแอนิเมชันจะเห็นเนื้อหาแบบนิ่ง ๆ
- Responsive: desktop เป็นไทม์ไลน์สลับซ้าย–ขวา, มือถือยุบเป็นคอลัมน์เดียวเส้นชิดซ้าย
- ไม่มี build step ไม่มี dependency ที่ต้องติดตั้ง
